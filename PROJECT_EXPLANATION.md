# DataSphere – Project Explanation

## 1. Introduction

DataSphere is a MongoDB-based Big Data Processing and Analytics System developed using Python. It stores e-commerce data in MongoDB, processes the records and presents useful analytical information through a Streamlit dashboard.

## 2. Problem Statement

Large e-commerce datasets contain information about products, customers, orders and reviews. Analysing this information manually is difficult. DataSphere provides a system to store, process and analyse this information efficiently.

## 3. Objectives

- Store e-commerce data in MongoDB.
- Process large volumes of records.
- Perform data analysis using Python.
- Generate analytical reports.
- Visualize results through charts and dashboards.

## 4. Technologies Used

- Python: Main programming language.
- MongoDB: NoSQL database.
- PyMongo: Connects Python with MongoDB.
- Pandas: Organizes and processes analytical results.
- Streamlit: Creates the interactive dashboard.

## 5. Implementation

The Olist e-commerce dataset is imported into MongoDB collections. Python connects to the database using PyMongo. MongoDB aggregation operations are used to group, sort and calculate information. Pandas organizes the results, and Streamlit displays them through charts, tables and metrics.

## 6. Analytical Operations

1. Total product count.
2. Total order count.
3. Average customer review score.
4. Order status analysis.
5. Top 10 product categories.
6. Revenue by product category.
7. Top 10 products by item-price value.
8. Customer review distribution.

## 7. Conclusion

DataSphere demonstrates how MongoDB and Python can be used together to store, process and analyse e-commerce datasets. The interactive dashboard makes the analytical results easier to understand and interpret.
